## Upload with GitHub Desktop
1. Open **GitHub Desktop** → File → Add Local Repository if you already use Git for your project. Otherwise use **File → New Repository** and choose the extracted project folder (or create a new Git-enabled folder and copy the project files into it).
2. Set repository name, e.g. `starlight-cinemas-assignment`.
3. Check the Changes tab; ensure the contents are the website files, `README.md`, and `docs/`.
4. Add your real name/course details and screenshots to documentation.
5. Write meaningful commit messages reflecting actual changes you make, then click **Commit to main**.
6. Click **Publish repository**; choose public/private according to your teacher's instructions.
7. Open the resulting GitHub URL, confirm `index.html`, `css/`, `js/`, `images/`, `README.md`, `docs/` and the commit history are visible.
8. Submit the repository URL in the required submission location before the deadline.

## At least five meaningful commits
The assignment asks for five meaningful commits. **Do not fabricate earlier development history** or split unchanged files into artificial commits. If your history already has five meaningful commits, preserve them. If not, make genuine improvements and commit each separately, for example:
- `docs: add project overview and setup instructions`
- `docs: add verified feature test results`
- `fix: resolve a tested form validation issue`
- `style: improve keyboard focus visibility`
- `docs: add screenshots and AI assistance disclosure`
Only use these messages for changes actually made.
